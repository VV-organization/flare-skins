# Дизайн-направление FLARE

Тезис: предметная витрина с редакционной типографикой, оранжевым акцентом и крупными открытыми композициями.

## Источники и применение

| Блок | Наблюдаемый источник | Адаптация |
| --- | --- | --- |
| Hero | Trionn: крупный левый заголовок, объёмный центральный объект; Hobro: крупное слово | Реальный скин поверх большого типографического поля, без старого тора |
| Пополнения | Приложенный скриншот: два самостоятельных калькулируемых действия | Меняем порядок и позицию; линии/типографика Trionn, оранжевый Boc |
| Подборка | Boc Work: узкая левая колонка, широкие ряды изображений, подписи под ними | Левый заголовок + открытые товарные ряды, без SaaS-карточек |
| Текстовый переход | bleibtgleich: асимметрично сдвинутые крупные строки, вертикальная линия | Короткое сообщение о выборе собственного стиля |
| Категории | Hobro Services: широкие нумерованные строки, тонкие разделители | Категории с предметом в активной строке и ссылкой в каталог |
| Подбор по цвету | Boc: левый фильтр + изображения в правом поле | Цвет и бюджет слева, результаты справа |
| Apple | bleibtgleich: разделение поля вертикальной осью; Trionn: крупный предмет | Типографическая карта и функциональная правая колонка, без чужих иллюстраций |
| Конвертер | Приложенный блок: подчёркнутая арифметика | Два поля на нижней позиции пополнений Frags |
| FAQ | Hobro Services: типографические строки | Доступный details/summary, номера и разделители |
| Footer | Hobro LET’S TALK: огромное одно действие | Крупное «ТВОЙ ХОД» и переход в каталог |

## Токены

Измерено Boc: body rgb(24,29,33); header rgba(255,68,33,.97). Проектный акцент #ff4421 из этого значения, фон #101112 (адаптация тёмного Trionn), текст #f4f4ef, поверхность #1b1d1e, линия #3b3d3e, muted #a5a6a2. Светлые разделы #f0f0e9 по белому/чёрному контрасту bleibtgleich/Hobro. Orange — основной акцент пользователя, без розового Frags.

Шрифт Manrope с кириллицей и OFL из Frags; плотность/масштаб адаптируют крупный grotesk референсов (Trionn использует Familjen). Заголовки 64–150 desktop, 42–72 mobile. Body 16; рабочие labels 14. Поля и кнопки не менее 44 px. Поля страницы 40 desktop, 20 mobile. Сетка открытая, без набора одинаковых скруглённых панелей.

## Движение

| Элемент | Приём | Проектное исполнение |
| --- | --- | --- |
| Hero | Trionn предметное движение | Мягкий pointer tilt, неподвижно на touch/reduced motion |
| Заголовки | Hobro/bleibtgleich постепенное раскрытие | 650–850 ms, translate/clip, содержимое доступно сразу |
| Предмет | Boc смена/движение превью | Hover scale 1.04, 350 ms; кликабельно и с клавиатуры |
| Категории | Hobro широкие интерактивные строки | Активный фон/изображение 250 ms, focus=hover |
| Прокрутка | Trionn смена видимости текста | IntersectionObserver reveal без scroll-jacking |

Длительности — наши проектные значения, не измеренные параметры оригиналов. Без декоративной анимации цен, загрузочного ожидания и захвата скролла. Секции остаются видимыми при отключенном JS.
