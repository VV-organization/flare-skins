# Сравнение дизайна, 27.09.2026

Проверены опубликованные главные страницы и каталоги:
- https://shop-skin.com/ — Creeps: CSS задаёт Unbounded для заголовков, Manrope для интерфейса; синий текстурный фон, лаймовые кнопки, наклонная сетка товаров в hero, рамочные карточки.
- https://vv-organization.github.io/frags-site/ — Manrope; чёрно-розовая палитра, большой предмет рядом с текстом, частицы, блочная сетка товаров, левое арт-превью категорий, парные тёмные формы.

Предыдущая пара FLARE Unbounded + Manrope совпадала с Creeps. Унаследованные категории и формы оставались слишком близки Frags. Одной смены цвета недостаточно.

## Выполненные изменения

- Oswald для акцентной типографики, Golos Text для чтения и интерфейса. Локальное подключение; прежняя пара больше не используется.
- Светлый hero с вертикальной осью и смещённым текстом по bleibtgleich; изображение отдельно от заголовка. Убраны указательный параллакс и большой нож поверх текста. Предмет появляется через раскрытие маски, с учётом reduced motion.
- Товарная подборка широкими рядами: изображение слева, подпись справа, по Boc Work. Кнопки добавления квадратные.
- Категории раскрываются внутри полноширинных строк по Hobro Services. Прежнего двухколоночного арт-блока нет.
- Пополнение: Steam на оранжевой поверхности слева, баланс на светлом поле справа. Поля с нижней линией и контрастные тёмные кнопки.
- Светлый каталог: плакатный заголовок, компактные текстовые категории без изображений, открытые карточки.
- FAQ в две колонки на desktop; типографика и оранжевый footer поддерживают новое направление.

Порядок разделов сохранён. Стандартные элементы магазина (поиск, суммы, корзина, фильтры) остаются узнаваемыми по назначению. Это визуальный аудит, а не утверждение об абсолютной уникальности каждого элемента.

## Проверки

Главная: desktop 1440, mobile 390 и 320; горизонтального переполнения нет. Новые категории раскрываются нажатием. Шрифты в computed styles — Oswald и Golos Text. 17 существующих тестов прошли; lint, TypeScript и production build прошли.

## Повторная проверка текста и остаточных совпадений

Предыдущая редакция сохраняла язык Frags даже после смены оформления. Переписаны тексты главной, каталога, карточки, пополнений, Apple, калькулятора, корзины, кабинета и окна входа. Правила зафиксированы в COPY_DIRECTION.md.

Вместо большого слогана добавлена справка о параметрах предмета в той же позиции страницы. Подборка заменена на четыре покрытия с оранжевыми деталями. Подвал стал навигационным блоком с логотипом; удалён «Твой ход». Удалены декоративные номера у товаров и FAQ. Осмотр предмета открывается на светлом фоне, без большой фоновой надписи и угловых меток. Пустая корзина без заимствованной сцены с ножом. Корзина и кабинет на светлой основе, навигация кабинета горизонтальная.

Проверены главная 320 px, корзина 390 px, кабинет 320/390 и 1440 px; переполнения нет. Переключение вкладки покупок проверено. 17 тестов, lint, TypeScript и production build прошли. Совпадения в коротких функциональных обозначениях и параметрах товаров сохранены намеренно.
