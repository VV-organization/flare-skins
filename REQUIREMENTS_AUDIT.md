## Проверки

- `npm test`: 17/17, money, discovery, filters, catalog contract, Steam validation, fail-closed financial routes.
- `npm run typecheck`, `npm run lint`, `npm run build`: успешно.
- `npm run build:pages`: успешно, 74 статических страницы; серверная сборка — 76 страниц/маршрутов.
- Браузер: главная 320/390/768/1440; исправлены выход картинки категории и min-content переполнение подбора/Apple на 320. После исправлений scrollWidth = clientWidth (305, 375, 753 соответственно).
- Steam 2 000 ₽ -> комиссия 100 ₽ -> итог 2 100 ₽. Неверный ID 123 показывает ошибку, аккаунт не подтверждается.
- Apple: смена US -> TR сбрасывает совместимость и блокирует продолжение до нового подтверждения; проверка сообщает о временной недоступности.
- Поиск Printstream -> 1 товар; быстрый просмотр -> корзина с 1 674,14 FLARE / 2 511,21 ₽. Контраст итогов корзины исправлен.
- Кабинет: просмотр пустой истории; отмена выхода сохраняет локальное состояние. Mobile кабинет и карточка без горизонтального переполнения на 390.
- CSS reduced-motion отключает декоративные анимации и smooth scroll; клавиатурные диалоги используют native dialog, Escape и восстановление фокуса.
- Переименование motion-компонента дало промежуточную HMR-ошибку во время правки; обе финальные production-сборки прошли. Продукт не зависит от девелоперского HMR.

## Ограничения

Нет контрактов/доступов к оплате, вендору и выдаче, Steam OpenID, поставщику Apple. Не тестировались реальные деньги или выдача. Каталог — снимок, локальный кабинет не серверная сессия. Номиналы Apple — предварительный интерфейс, не гарантированный ассортимент. Юридические данные, имя бренда и коммерческие условия требуют исходных данных владельца перед запуском.
